# Wispr Flow features

<DisclosureNotice />

**Wispr Flow's core feature is voice dictation that types cleaned-up text into any app. Around that, it adds automatic editing, Command Mode for editing by voice, tone modes, a personal dictionary, snippets, a meeting Notetaker, and support for 100+ languages. Here is the full list in plain English, with links to the features worth a deeper look.**

## Core dictation

- **Type by voice anywhere.** Works in any text field, no plugin required: email, chat, docs, editors, terminal, and AI tools like ChatGPT, Claude, and Cursor.
- **Automatic cleanup.** Removes filler words ("um", "you know"), adds punctuation, and formats structured content like lists and emails.
- **Self-correction handling.** Catches mid-sentence corrections, so "send it at 5, actually 6pm" becomes "send it at 6pm".
- **Strong speech detection.** Wispr Flow says it handles fast talkers, whispering, and noisy environments.

## Editing and control

- **[Command Mode](/docs/guides/command-mode/).** Edit and format existing text with spoken commands, not just dictate new words.
- **Tone modes.** Adapt the output between formal, casual, and very casual styles.
- **[Keyboard hotkeys](/docs/guides/keyboard-shortcuts/).** Hold-to-dictate, configurable to avoid clashes.

## Personalization

- **[Personal dictionary](/docs/guides/custom-dictionary/).** Learns your names, acronyms, and jargon so they stop getting mistranscribed.
- **Snippets.** Reusable text shortcuts for phrases you type often.

## Languages and platforms

- **100+ languages** with automatic detection, so you can switch languages without changing a setting.
- **Runs on Mac, Windows, iPhone, and Android.** No native Linux app; see the [Linux page](/docs/use/linux/).

## Meetings

- **[Notetaker](/docs/guides/wispr-flow-notetaker/).** Captures meeting notes you can review, share, and feed into AI tools. Limited on Free, extended on Pro, unlimited on Growth.

## Feature availability by plan (summary)

| Feature | Free | Paid (Pro and up) |
|---|---|---|
| Dictation, 100+ languages | Yes (weekly word cap) | Yes (unlimited) |
| Auto-editing, Command Mode, tone modes | Yes | Yes |
| Personal dictionary, snippets | Yes | Yes (shared on teams) |
| Notetaker | Limited (Mac) | Extended (Pro) / Unlimited (Growth) |
| SSO, HIPAA, admin controls | No | Growth and Enterprise |

Exact limits and prices change; see the [pricing guide](/docs/review/wispr-flow-pricing/) and Wispr Flow's site for current details.
