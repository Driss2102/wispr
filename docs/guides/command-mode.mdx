# Wispr Flow Command Mode

<DisclosureNotice />

**Command Mode lets you edit and format the text you dictated using spoken commands, not just add new words. While dictating you can say things like delete that, capitalize it, add a comma, make it a bullet list, or new paragraph, and Wispr Flow applies the edit. It is voice control over your own words. It is not an AI that rewrites or improves your writing, and it never changes what you meant to say.**

## What Command Mode does

Normal dictation types what you say. Command Mode adds a layer of voice control on top: instead of only speaking new text, you can give short editing and formatting instructions about the text you just dictated. Think delete, capitalize, punctuate, start a new line, or format as a list, hands-free.

## When it is useful

- **Formatting hands-free**, for example turning what you dictated into a bulleted list.
- **Quick corrections by voice**, like deleting the last phrase or fixing capitalization.
- **Adding structure**, such as new paragraphs or punctuation, without reaching for the keyboard.
- **Accessibility**, when using the keyboard is difficult or your hands are busy.

## How to get the most from it

- Dictate the content first, then use Command Mode to format and tidy it.
- Keep commands short and specific ("new paragraph", "make this a list", "capitalize that").
- Combine it with a [custom dictionary](/docs/guides/custom-dictionary/) so names stay correct.
- For the exact current command syntax, check Wispr Flow's own [help center](https://docs.wisprflow.ai/), since commands can change between versions.

## An honest note

Voice commands are handy for formatting and quick edits, but not always faster than a keyboard fix for a single character. Command Mode earns its place for hands-free formatting and structure, less so for tiny one-word tweaks. Use it where it genuinely saves effort.
