# Use Wispr Flow in Google Docs

<DisclosureNotice />

<HowToSchema name="Dictate in Google Docs with Wispr Flow" appName="Google Docs" />

**Wispr Flow types into Google Docs like any editor: click into the document, hold your hotkey, and speak. Compared with Google Docs' built-in voice typing, Wispr Flow does stronger cleanup (filler removal, punctuation, tone) and works the same way across all your other apps, not just Docs. For casual dictation inside Docs, Google's free tool is fine; for cleaner output everywhere, Wispr Flow wins.**

## Wispr Flow vs Google's built-in voice typing

Google Docs has free voice typing (Tools > Voice typing), but it does lighter cleanup and lives only in Docs. Wispr Flow adds automatic editing and works system-wide, so the same dictation habit carries to Gmail, Slack, and your editor. See the full [Wispr Flow vs Google Voice Typing](/docs/compare/wispr-flow-vs-google-voice-typing/) comparison.

## How to use it

Install Wispr Flow on [Mac](/docs/use/mac/) or [Windows](/docs/use/windows/), open your Google Doc in the browser, click into the document, hold the hotkey, and dictate. On mobile, use the Wispr Flow keyboard in the Docs app.

## A good workflow for long documents

Dictate the draft in one pass without stopping to format, let Wispr Flow clean it, then use Google Docs' keyboard tools for headings, styles, and precise edits. Talking the content and typing the structure is faster than doing both at once.
