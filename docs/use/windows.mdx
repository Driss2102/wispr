# How to use Wispr Flow on Windows

<DisclosureNotice />

<HowToSchema name="Dictate in Windows with Wispr Flow" appName="Windows" />

**To use Wispr Flow on Windows, download the Windows app, allow microphone access, then hold your dictation hotkey in any text field and speak. Wispr Flow types cleaned-up text wherever your cursor is, across Outlook, Word, browsers, Slack, and your code editor.**

## Install and set up (step by step)

1. Download the Windows app from the [official Wispr Flow site](https://wisprflow.ai/) and run the installer.
2. Open Wispr Flow and allow **microphone** access when Windows asks.
3. Check your input device (Settings > System > Sound) if you use a headset or external mic.
4. Note the dictation hotkey in the app and test it in Notepad or a browser search box.

## Dictating on Windows

Place your cursor, hold the hotkey, and talk. Pause and self-correct as you go; Wispr Flow cleans filler words and adds punctuation before inserting the text. Because it types where the cursor is, the same flow works in almost every Windows app.

## Common Windows snags and fixes

- **No text inserted.** Make sure Wispr Flow is running (check the system tray) and that the target window has focus.
- **Mic not detected.** Set the correct input under Sound settings and confirm the app has microphone permission (Settings > Privacy & security > Microphone).
- **Hotkey conflict.** If another app uses the same shortcut, change the hotkey inside Wispr Flow.

For deeper audio issues, see [fix microphone problems](/docs/guides/fix-microphone/).
