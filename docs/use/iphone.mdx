# How to use Wispr Flow on iPhone

<DisclosureNotice />

<HowToSchema name="Dictate in iPhone with Wispr Flow" appName="iPhone" />

**On iPhone, Wispr Flow works through its keyboard: install the app, enable the Wispr Flow keyboard in iOS Settings, grant microphone access, then tap to dictate in any app. Note that the free plan gives fewer words per week on iPhone (1,000) than on desktop (2,000).**

## Install and set up (step by step)

1. Install Wispr Flow from the App Store and open it once to sign in.
2. Go to **Settings > General > Keyboard > Keyboards > Add New Keyboard** and add Wispr Flow.
3. Tap the Wispr Flow keyboard and enable **Allow Full Access** (needed so it can process dictation).
4. Grant microphone access when prompted.
5. In any app, switch to the Wispr Flow keyboard (the globe key) and start dictating.

## Dictating on iOS

Tap to start, speak naturally, and Wispr Flow inserts cleaned-up text into the field. It is handy for replies, notes, and messages where thumb-typing is slow. Because it is a keyboard, it works in most apps that accept text input.

## Free words are lower on iPhone

As of 2026 the free plan allows about 1,000 words per week on iPhone versus 2,000 on desktop. If you dictate a lot on mobile, you will hit the cap sooner; Pro removes it. Interestingly, the free plan is unlimited on Android, which we cover on the [Android page](/docs/use/android/).
