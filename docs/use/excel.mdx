# Use Wispr Flow in Excel and Google Sheets

<DisclosureNotice />

**Wispr Flow can type into Excel and Google Sheets cells, so it works for dictating text-heavy content: notes, descriptions, comments, and long labels. It is not a good fit for the numeric and structural side of spreadsheets, entering formulas, navigating between cells, or precise data entry, which are all faster and more reliable by keyboard. Use it for the words, not the numbers.**

## Where dictation helps in spreadsheets

- **Text-heavy cells:** descriptions, notes, qualitative feedback, long labels.
- **Comments and documentation** within a sheet.
- **Drafting content** that will live in a spreadsheet (for example a content calendar's notes column).

## Where the keyboard wins

- **Formulas.** Dictating `=SUMIF(...)` is slower and error-prone.
- **Navigation.** Moving between cells, rows, and tabs is a keyboard and mouse job.
- **Numeric data entry.** Precise numbers are faster and safer typed.

## A realistic workflow

Type the structure and formulas, and dictate the wordy cells. If a sheet is mostly text (notes, research, qualitative logs), dictation saves real time; if it is mostly numbers and formulas, it will not.

## How to use it

Install Wispr Flow on [Mac](/docs/use/mac/) or [Windows](/docs/use/windows/), open Excel or Google Sheets, click into a text cell, hold your hotkey, and dictate.
