# Use Wispr Flow in Cursor and VS Code

<DisclosureNotice />

<HowToSchema name="Dictate in Cursor and VS Code with Wispr Flow" appName="Cursor and VS Code" />

**Wispr Flow works in Cursor and VS Code with no extension: click into the editor, the AI chat pane, or the terminal, hold your hotkey, and speak. It shines for dictating AI prompts, comments, commit messages, and prose. It is weaker for typing exact code syntax, which is still faster on a keyboard.**

## Where it helps developers most

- **AI prompts in Cursor.** Speaking a full, contextual request to the agent beats typing a terse one.
- **Comments and docstrings.** Explaining intent in plain language is quick by voice.
- **Commit messages and PR descriptions.** These are prose, so dictation is a good fit.
- **Chat and issues.** Slack, GitHub, and Linear fields all accept dictated text.

## Where it does not

Dictating literal syntax (brackets, camelCase, operators, indentation) is slower and error-prone. The realistic workflow is hybrid: dictate the natural-language parts and type the code. Our [dictate code guide](/docs/guides/dictate-code/) goes deeper, including a [custom dictionary](/docs/guides/custom-dictionary/) for library and function names.

## Setup

Install Wispr Flow on [Mac](/docs/use/mac/) or [Windows](/docs/use/windows/), open Cursor or VS Code, place your cursor in any field, and use your dictation hotkey. On Mac, make sure Accessibility permission is granted so it can type into the editor.
