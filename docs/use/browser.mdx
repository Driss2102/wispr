# Use Wispr Flow in your browser

<DisclosureNotice />

<HowToSchema name="Dictate in your browser (Chrome, Edge, Safari) with Wispr Flow" appName="your browser (Chrome, Edge, Safari)" />

**Wispr Flow works in any browser, Chrome, Edge, Safari, or Firefox, without an extension, because it types into whatever field has your cursor. That covers web apps (Gmail, Notion, Jira, LinkedIn), search boxes, forms, and comment fields. You install the desktop app once, and it works across every site you visit.**

## No extension needed

Because Wispr Flow types at the system level, it does not need a browser extension or per-site setup. Click into any text field on any website, hold your hotkey, and dictate. That is why one install covers all your web apps at once.

## Where it helps in the browser

- **Web-based email and chat** (Gmail, Outlook web, Slack, Teams).
- **Docs and notes** (Google Docs, Notion, web editors).
- **Project tools** (Jira, Linear, GitHub) for descriptions and comments.
- **Search and forms** where you would otherwise type.

## How to use it

Install Wispr Flow on [Mac](/docs/use/mac/) or [Windows](/docs/use/windows/), open your browser, click into any field, hold your hotkey, and speak. On Mac, make sure the Accessibility permission is granted so it can type into the browser.
