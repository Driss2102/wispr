# Wispr Flow on Linux: what to do

<DisclosureNotice />

**As of 2026, Wispr Flow has no native Linux app. It runs on Mac, Windows, iPhone, and Android only. If Linux is your main machine, you have three realistic options: dictate on a phone and sync the text, use Wispr Flow on a Mac or Windows machine you also own, or pick a Linux-friendly dictation tool instead.**

We flag this clearly because search interest in "Wispr Flow Linux" is rising, and it would be dishonest to imply support that is not there.

## Your realistic options on Linux

1. **Dictate on your phone.** The iPhone or (better, unlimited on free) Android app lets you dictate into notes or a chat, then copy or sync the text to your Linux machine. Clumsy, but it works today.
2. **Use Wispr Flow on a Mac or Windows device.** If you have a second machine, Wispr Flow runs there normally.
3. **Use a Linux-native option.** Open-source tools built on OpenAI's Whisper model can do local dictation on Linux. They need more setup and lack Wispr Flow's polish, but they run where you work. See our [Wispr Flow vs OpenAI Whisper](/docs/compare/wispr-flow-vs-openai-whisper/) page for how the underlying model differs from a finished app.

## Should you wait for a Linux app?

We have no confirmation that a Linux version is planned, so do not plan around one. If a native Linux app matters to you, treat it as absent and choose based on what exists now.
