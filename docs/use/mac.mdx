# How to use Wispr Flow on Mac

<DisclosureNotice />

<HowToSchema name="Dictate in Mac with Wispr Flow" appName="Mac" />

**To use Wispr Flow on Mac, download the macOS app, grant it Microphone and Accessibility permissions, then hold your dictation hotkey in any text field and speak. The Accessibility permission is the step people miss: without it, Wispr Flow can hear you but cannot type into other apps.**

## Install and set up (step by step)

1. Download the Mac app from the [official Wispr Flow site](https://wisprflow.ai/) and open the installer.
2. Launch Wispr Flow. On first run macOS will ask for **Microphone** access. Allow it.
3. Grant **Accessibility** access when prompted (System Settings > Privacy & Security > Accessibility). This lets Wispr Flow insert text into other apps.
4. Note your dictation hotkey shown in the app, and try it in a note or your browser's address bar.

## Dictating on macOS

Put your cursor where you want text, hold the hotkey, and talk normally. You can pause and ramble; Wispr Flow removes filler words and adds punctuation. Release the key and the cleaned-up text appears. It works system-wide, so the same flow applies in Mail, Safari, Slack, and your editor.

## Common Mac snags and fixes

- **Text is not appearing in other apps.** Accessibility permission is off or was reset by a macOS update. Re-enable it in System Settings.
- **Wrong microphone.** Set your preferred input in the app and in System Settings > Sound.
- **Nothing happens on the hotkey.** Another app may have claimed the same shortcut; change the hotkey in Wispr Flow.

See the full [microphone troubleshooting guide](/docs/guides/fix-microphone/) if audio is the problem.
