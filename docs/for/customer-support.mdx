# Wispr Flow for customer support

<DisclosureNotice />

**Support work is high-volume writing under time pressure, which is exactly where dictation helps. With Wispr Flow, agents can speak replies that come out clean and correctly punctuated, adjust tone to match the customer, and use snippets for repeated phrases. It complements canned macros rather than replacing them: dictate the personalized parts, drop in macros for the standard bits.**

## Where it helps agents

- **Personalized replies at speed.** Speaking a tailored answer is faster than typing one.
- **Tone control.** Match a warm or formal tone to the ticket.
- **Snippets for repeats.** Combine dictation with saved snippets for common answers.
- **Fewer typos under pressure.** The cleanup handles punctuation you would otherwise fix.

## Where macros still win

For truly identical answers, a canned macro is faster than dictating the same thing again. The best setup is hybrid: macros for the standard shell, dictation for the specific detail that makes a reply feel human.

## Team and security note

If you are rolling this out to a team, the [Growth plan](/docs/review/wispr-flow-pricing/) adds shared dictionaries, admin controls, and security features. For regulated support (health, finance), review the compliance terms first; see [is Wispr Flow safe](/docs/review/is-wispr-flow-safe/).
