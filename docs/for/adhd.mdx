# Wispr Flow for people with ADHD

<DisclosureNotice />

**Two things about ADHD make voice dictation genuinely helpful: thoughts arrive fast and can vanish before you type them, and the blank page can be a hard place to start. Speaking lets you capture an idea the moment it appears and lowers the activation energy of writing. Wispr Flow's cleanup means the captured text is usable, not a mess you dread editing.**

This is a practical productivity take, not medical advice.

## Where it helps

- **Capture before it is gone.** Hold the hotkey and say the thought into any note; it is saved before the moment passes.
- **Lower the starting friction.** Talking is easier to start than typing a first sentence.
- **Momentum.** Getting words out fast keeps you moving instead of stalling on phrasing.

## A low-friction setup

1. Keep a single capture note open (in [Notion](/docs/use/notion/), [Obsidian](/docs/use/obsidian/), or notes).
2. Set an easy [hotkey](/docs/guides/keyboard-shortcuts/) so capturing is instant.
3. Dictate freely; tidy later. The point is to catch the thought, not to perfect it.

## An honest note

Dictation helps capture and drafting; it does not organize or prioritize for you. Pair it with whatever system you already use to sort notes. And if talking out loud is hard in your environment, the mobile app lets you capture quietly elsewhere.
