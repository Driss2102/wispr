# Wispr Flow Guide

An independent review-and-setup guide for [Wispr Flow](https://wisprflow.ai/), the
AI voice dictation app. Built with Docusaurus 3. Not affiliated with Wispr AI, Inc.

## Develop

```bash
npm install
npm start        # dev server at http://localhost:3000
npm run build    # production build into /build
npm run serve    # serve the built site
```

See `CLAUDE.md` for architecture and content rules, `HANDOFF.md` for launch steps,
and `research/` for the fact ledger and style bar.
